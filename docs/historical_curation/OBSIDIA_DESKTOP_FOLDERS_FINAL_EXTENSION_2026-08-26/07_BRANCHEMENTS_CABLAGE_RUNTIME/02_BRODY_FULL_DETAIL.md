## E. Interdictions Brody — absolues

| Règle | Conséquence si violée |
|---|---|
| **Brody ne décide JAMAIS** | BLOCK/HOLD/ALLOW = KX108_ONLY — Brody éduque uniquement | Violation autorité X-108 |
| **Brody ne retourne pas BLOCK/HOLD/ALLOW** | Toute "décision" Brody = artefact non souverain | Confusion verdict |
| **Brody ne write pas Graphiti** | memory_write=false permanent | Corruption mémoire |
| **Brody ne bypass pas Kernel** | Toute requête passe par API 8000 → gate → Kernel 3001 | Bypass gate = violation |
| **BrodyDisclosureGuard filtre — ne décide pas** | Filtre PUBLIC/INVESTOR/TECHNICAL_AUDIT | Fuite contexte kernel brut |
